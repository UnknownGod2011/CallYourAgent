CallYourAgent is not a phone bot. It is a control plane between an autonomous agent and the human responsible for its work.

01 / AGENT ESCALATES

Ask at the right moment

When an agent needs actual judgment, it creates a branch-scoped decision request instead of guessing or freezing the entire task.

02 / YOU TALK

Answer naturally

The phone transport collects the conversation and returns a structured outcome. The agent never gets your provider key.

03 / WORK CONTINUES

Consume safely

Answers and steering wait in a durable queue until the next explicit checkpoint. No fake mid-generation interruption.

Codex CLI / IDE

Install the local MCP connector, then restart Codex and confirm it from /mcp.

codex mcp add callyouragent \
  --env CYA_BASE_URL=https://YOUR-CONTROL-PLANE \
  --env CYA_API_TOKEN=YOUR_SCOPED_AGENT_TOKEN \
  -- node /absolute/path/to/CallYourAgent/dist/src/mcp-server.js

Hosted ChatGPT and ChatGPT Work need a remote MCP endpoint with per-user OAuth. That hosted connector is not live yet.

Safety by design

Useful calls without handing your agent the keys.

◉
Scoped credentials

The agent only receives its own least-privilege token. Provider keys and the owner credential remain server-side.

⌁
Safe checkpoints

Owner instructions are stored, pulled, and acknowledged at a clear boundary in the agent’s work loop.

◇
Provider independent

Phone delivery can change behind the control-plane contract as long as it returns a verified lifecycle and structured outcome.
